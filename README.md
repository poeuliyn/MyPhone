# MyPhone

มือถือจำลองสไตล์ iOS สำหรับ SillyTavern — เขียนขึ้นใหม่ทั้งหมด (ไม่ได้อิงโค้ดจาก extension อื่น) เพื่อให้เป็นของคุณเองและต่อยอดเองได้

**เวอร์ชันนี้ (0.1.0) คือเฟสแรก:** โครงมือถือ + แอปข้อความ (Messages)
แอปอื่น (เฟสบุ๊ค, ดิสคอร์ด, กูเกิ้ล, อีเมล, ธนาคาร, ช็อปปิ้งที่เชื่อมกับแชทหลัก) จะทยอยเพิ่มในเวอร์ชันถัดไป — ตอนนี้ขึ้นเป็นไอคอนบนโฮมสกรีนไว้ก่อน (แตะแล้วจะขึ้น "กำลังจะมา")

## ติดตั้ง

1. ใน SillyTavern ไปที่ Extensions → Install extension → ใส่ลิงก์ GitHub ของ repo นี้
2. หรือก็อปโฟลเดอร์นี้ทั้งหมดไปไว้ที่ `public/scripts/extensions/third-party/myphone` แล้วรีโหลดหน้าเว็บ

## วิธีใช้

- จะมีปุ่มวงกลม 📱 ลอยอยู่มุมขวาล่างของหน้าจอ กดเพื่อเปิดมือถือ
- หน้าล็อกสกรีน แตะที่ไหนก็ได้เพื่อปลดล็อก
- หน้าโฮม แตะไอคอนแอปเพื่อเปิด (ตอนนี้ใช้งานได้จริง: **ข้อความ** และ **ตั้งค่า**)
- กดปุ่ม ✕ มุมขวาบนของกรอบมือถือเพื่อปิด

## แอปข้อความ (Messages)

- **ผู้ติดต่อขึ้นเองอัตโนมัติจากแชทหลัก** — ไม่ต้องสร้างเอง ตัวละครจะโผล่เป็นช่องแชทให้ทันทีถ้า:
  1. เคยพูดในแชทหลักของ ST หรือ
  2. ชื่อถูกเอ่ยถึงในเนื้อความแชทหลัก (ใครพิมพ์ก็นับ ทั้งผู้ใช้และตัวละครอื่น) หรือ
  3. เคยมีประวัติคุยกับเราในแอปนี้มาก่อนแล้ว (กันไม่ให้หายไปจากลิสต์ทีหลัง)
- อัปเดตสด — ถ้าเปิดมือถือค้างไว้แล้วมีข้อความใหม่ในแชทหลักที่เอ่ยชื่อใคร คนนั้นจะโผล่ในลิสต์ทันทีไม่ต้องปิดเปิดแอปใหม่
- แชทที่คุยในนี้เป็นคนละส่วนกับแชทหลักของ ST โดยสิ้นเชิง (ไม่ผสมกับเนื้อเรื่องหลัก ไม่ฉีดข้อความเข้าไปในบทหลัก)
- ใช้ API หลักที่ตั้งไว้ใน SillyTavern ในการเจนคำตอบ (ยังไม่มีระบบแยก API ในเวอร์ชันนี้ — เพิ่มได้ทีหลังถ้าต้องการ)
- ประวัติแชทถูกเก็บผ่านระบบตั้งค่าของ ST เอง (`extensionSettings`) ติดไปกับโปรไฟล์ ST ของคุณ

## ตั้งค่า (Settings)

ปรับแต่งได้ทั้งหมดโดยไม่ต้องแก้โค้ด:

- **โหมดสี** — มืด / สว่าง
- **สีเน้น** — สีของปุ่ม/ข้อความที่คุณส่ง เลือกจาก 8 สี
- **วอลเปเปอร์** — พรีเซ็ต 6 แบบ หรือใส่ลิงก์รูปเองก็ได้
- **ธีมไอคอนแอป** — คลาสสิก / โมโนโครม / พาสเทล / นีออน (เปลี่ยนสีไล่เฉดของไอคอนทุกแอปพร้อมกัน)
- **รูปแบบนาฬิกา** — บาง (แบบ iOS ปกติ) / หนา / ดิจิทัล / หัวเอียง

## โครงสร้างโค้ด (สำหรับแก้ต่อเอง)

- `index.js` — ทุกอย่างอยู่ในไฟล์เดียว แบ่งเป็นส่วน ๆ ด้วยคอมเมนต์:
  - ค่าคงที่ (ไอคอน, ค่าเริ่มต้น, วอลเปเปอร์, ธีมไอคอน, สไตล์นาฬิกา, รายชื่อแอป)
  - `getCfg()`/`saveCfg()` — อ่าน/บันทึกการตั้งค่า
  - ระบบเจนข้อความ (`mpGenerate`, `buildPrompt`, `mpSendMessage`)
  - ฟังก์ชัน `render*()` แต่ละหน้าจอ — เพิ่มแอปใหม่คือเพิ่มฟังก์ชัน render ใหม่ + เพิ่มรายการใน `MP_APPS`
  - `wireEvents()` — event delegation จุดเดียวจับคลิกทั้งหมด (เพิ่มปุ่มใหม่คือเพิ่ม `if` ใหม่ในนี้)
- `style.css` — ใช้ CSS variable (`--accent`, `--ph-bg`, `--ph-wallpaper` ฯลฯ) ตั้งค่าผ่าน JS ใน `applyTheming()`

## แผนต่อไป (แนะนำเรียงลำดับ)

1. เฟสบุ๊ค (โพสต์ + กลุ่ม)
2. ดิสคอร์ด (สร้าง/เข้าคอมมูนิตี้)
3. อีเมล
4. ธนาคาร
5. กูเกิ้ล (เสิร์ช)
6. ช็อปปิ้ง — ซับซ้อนสุดเพราะต้อง "เชื่อมกับแชทหลัก" (สั่งของในมือถือ → มีข้อความ/เหตุการณ์โผล่ในแชทหลักของ ST) จะออกแบบระบบ "สะพานเชื่อม" (bridge) ตอนถึงเฟสนี้

บอกได้เลยว่าอยากให้ทำอันไหนต่อ

## ข้อจำกัดที่ควรรู้ (เวอร์ชันนี้)

- การเช็ค "เอ่ยชื่อ" ใช้วิธีค้นหาชื่อแบบ substring ธรรมดา (ไม่สนตัวพิมพ์เล็ก-ใหญ่) ถ้าตัวละครชื่อสั้นมากหรือพ้องกับคำทั่วไป อาจโผล่มาเป็นผู้ติดต่อทั้งที่ไม่ได้ตั้งใจพูดถึง — ปรับปรุงให้แม่นขึ้นได้ในเวอร์ชันถัดไปถ้าเจอปัญหานี้บ่อย
- การอัปเดตสดต้องพึ่ง event system ของ ST (`eventSource`/`event_types`) ถ้าเวอร์ชัน ST ที่ใช้ไม่มีสิ่งนี้ ระบบจะยัง fallback ไปอัปเดตตอนเปิด/ปิดแอปใหม่ตามปกติ (เช็ค console จะมีคำเตือนถ้าเกิดเหตุการณ์นี้)
